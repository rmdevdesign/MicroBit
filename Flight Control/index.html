micro:bit + USB Serial

Avion 3D pilote par manette

Fixez le micro:bit dans la manette, face visible et cable vers le bas. Tournez la manette pour le roulis, poussez ou tirez pour le tangage. La connexion passe maintenant par le cable USB pour eviter les soucis Bluetooth.

Installer le programme micro:bit

Telechargez le firmware, puis glissez le fichier sur le lecteur MICROBIT. Laissez ensuite le micro:bit branche en USB.
